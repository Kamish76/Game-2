## Purpose
One list of every stat the Bastion and its weapons can have, how bonuses stack, and how final values are computed.

### Weapon-local stats
Each weapon has its own `damage`, `cooldown`, `projectiles`, `projSpeed`, `size`, `pierce`, `bounces`, `critChance`, `range`, `knockback`. Weapon upgrades change **only** that weapon.

## Final value formula

```
final_weapon_stat = (weapon_base + weapon_local_flat) × (1 + weapon_local_% ) × (1 + global_%)  + global_flat
```

Examples:
- **Damage per hit** = `weapon.damage × globalDamageMult × critMult(if crit)`
- **Projectiles** = `weapon.projectiles + global.quantity`
- **Cooldown** = `weapon.cooldown / (1 + weapon.attackSpeed + global.attackSpeed)`, with a floor of 0.08 s
- **Radius** = `weapon.size × (1 + global.size)`

## Hyperbolic defense (why it's not linear)
- `armorReduction = A / (A + 100)` → 10 armor = 9%, 50 = 33%, 100 = 50%, 300 = 75%. You never reach 100%.
- `deflectChance = E / (E + 100)`, same curve.

> Megabonk uses `A / (0.75 + A)` on an internal 0–1 scale. Our *points* version is the same curve shape and easier for players to read. Decision logged in [DECISIONS_LOG.md](../DECISIONS_LOG.md).

## Recalculation
`StatEngine.recompute()` runs **only** when something changes (level-up pick, character passive on level, Phase 2 items). It writes a flat `StatSheet` that weapons read every frame. Weapons never sum modifiers per frame.
