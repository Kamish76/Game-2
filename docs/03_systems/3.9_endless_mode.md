# 3.9: Endless Mode Specification

## Purpose
Defines the structure of the primary game mode for the v1 prototype: endless survival with time-based escalation, periodic boss encounters, Overtime phase, and score calculation.

---

## 1. Run Timeline & Escalation Phases

```mermaid
timeline
    title Endless Mode Escalation Timeline
    00:00 - 03:00 : Phase 1 - Perimeter Setup : Low density Swarmlings & Runners. Initial weapon and tome draft.
    03:00 : Boss 1 : Yokai Goliath spawn. Tests single-target damage output.
    03:00 - 06:00 : Phase 2 - Armor & Range : Brutes and Spitters enter spawn rotation.
    06:00 : Boss 2 : Armored Goliath + minion wave.
    06:00 - 15:00 : Phase 3 - High Density Escalation : Mixed elite waves, rapid spawn credit scaling.
    15:00+ : OVERTIME (The Final Swarm) : Screen tint shifts red, spawn budget surges by 100%, endless survival test.
```

---

## 2. Overtime: The Final Swarm (15:00+)
At the 15:00 mark, the game transitions into **Overtime**, translating Megabonk's Final Swarm into the stationary defense context:
- **Visual / Audio Cue:** Ambient lighting darkens, red warning pulse at screen borders, intense battle theme.
- **Spawn Surge:** Spawn credits per second immediately double ($+100\%$).
- **Stat Scaling:** All enemies gain an escalating $+10\%$ HP and $+5\%$ Move Speed for every 30 seconds survived in Overtime.
- **Scoring Multiplier:** Surviving during Overtime awards $3\times$ score per second.

---

## 3. Score Calculation & Run Evaluation
Upon Bastion destruction (Structural HP $= 0$), the game transitions to the `GameOver` overlay and computes the final run score:

$$\text{Final Score} = \left(\text{Time}_{\text{sec}} \times 10 + \text{Kills} \times 5 + \text{BossKills} \times 250 + \text{Gold} \times 2\right) \times \text{OvertimeBonus}$$

Where:
- $\text{OvertimeBonus} = 1.0$ if ended before 15:00.
- $\text{OvertimeBonus} = 1.0 + \frac{\text{TimeOvertime}_{\text{sec}}}{60}$ if survived past 15:00.

### Results Screen Data Points
- Survival Duration (`MM:SS`)
- Bastion Level Reached
- Total Enemies Defeated (broken down by Elites and Bosses)
- Total Gold Vacuumed
- Final Score & New High Score Indicator
