# BONKHOLD Glossary of Terms

| Term | Definition |
|---|---|
| **Bastion** | The stationary defensive tower centered at coordinates $(0, 0)$ that the player protects. |
| **Factor Chassis** | The base tower class selected at run start (e.g. Kitsune Spire), determining starting weapons, passives, and visual theme. |
| **Tome** | A global modifier card that applies scaling percentages across all equipped weapons and core attributes simultaneously (capped at 4 slots). |
| **Weapon** | An automated turret module mounted on the Bastion that tracks and fires at targets (capped at 4 slots). |
| **Item Relic** | A passive collectible with unique proc triggers (on-hit, on-crit, on-damaged) with uncapped inventory stacking (Phase 2). |
| **Rarity Factor** | The mathematical multiplier applied to upgrade rolls: Common (1.0×), Uncommon (1.2×), Rare (1.4×), Epic (1.6×), Legendary (2.0×). |
| **Deflect (Evasion)** | A percentage roll that completely glances and negates an incoming attack, preventing damage from hitting armor or shields. |
| **Holy Trinity** | The synergistic scaling engine formed by stacking XP Tome, Luck Tome, and Cursed Tome. |
| **Curse** | A multiplier that increases enemy spawn frequency, movement velocity, and maximum health, while boosting XP and Gold drop yields. |
| **Overtime (Final Swarm)**| The climactic endless phase triggered after 15 minutes of survival where difficulty escalates drastically. |
| **Spatial Hash** | A 2D spatial partitioning grid used to accelerate neighborhood queries for auto-targeting, AoE explosions, and vacuum attraction in O(1) time. |
| **Warden** | A planned mobile drone companion operated by the player in Phase 2 to interact with field shrines and chests. |
